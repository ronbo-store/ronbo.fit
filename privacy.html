What this site collects · Qué recoge este sitio

  • The RONBO.FIT Business form. If you join the early-access list, the site sends us the three details you type — gym name, city and email — so we can write back to you. Nothing is stored in the page itself. El formulario de RONBO.FIT Business.   • Basic technical delivery. This site is served through GitHub Pages, which may keep standard technical logs (such as IP address and browser type) to deliver and protect the site. Entrega técnica básica. Este sitio se sirve a través de GitHub Pages, que puede guardar registros técnicos estándar (como la dirección IP y el tipo de navegador) para entregar y proteger el sitio.
  • Nothing else. This website has no accounts, no comments and no checkout. Nada más. Este sitio web no tiene cuentas, ni comentarios, ni pagos.

This website does not set advertising or tracking cookies of its own today, and no advertising code runs on it yet. Este sitio web hoy no instala cookies propias de publicidad ni de seguimiento, y todavía no corre en él ningún código publicitario.
